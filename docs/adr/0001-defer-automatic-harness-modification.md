# Defer automatic harness modification from the initial core

The initial core will establish bounded interventions around the frozen VLA and add outcome-linked cross-episode memory; the Q22 clarification on 2026-09-29 includes both predefined recovery tools and bounded numerical action adjustments in v1. Automatic harness modification remains deferred because it adds a separate patching, evaluation, and promotion system before supervision has demonstrated benefit. This preserves the sequencing accepted on 2026-09-27 while refining intervention scope; the initial self-improvement mechanism is defined in [ADR-0002](0002-improve-through-memory-with-frozen-models.md).
