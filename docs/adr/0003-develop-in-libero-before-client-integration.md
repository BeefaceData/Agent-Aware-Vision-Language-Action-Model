# Develop in LIBERO before client integration

Develop the initial system with the frozen `HuggingFaceVLA/smolvla_libero` policy in LIBERO-10 while the client's concrete interface is pending, then integrate the client's VLA and bimanual towel-folding setup. Preserve reusable harness, recording, supervisor-interface, and memory machinery while allowing policy/environment adapters, task descriptions, correction capabilities, limits, and relevant memory to differ; this advances independent development without claiming automatic transfer of one-arm correction semantics or measured performance. The team accepted this sequence and portability scope on 2026-09-27 and expects physical client integration by the October milestone, after the client's simulation-improvement gate. In Q20 on 2026-09-29, the team accepted a transfer probe that freezes harness logic and supervisor prompt templates, permits necessary adapters, task instruction and robot configuration, starts with empty cross-episode memory, and measures the client task before task-specific tuning; simulation-memory transfer is a separate optional experiment.
