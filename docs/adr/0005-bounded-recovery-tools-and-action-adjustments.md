# Permit bounded recovery tools and action adjustments in v1

The Q21-Q22 answers on 2026-09-29 require robust failure detection and permit both predefined recovery tools executed by validated code and bounded numerical adjustments to the frozen VLA's proposed actions. Supervisor decisions use deployable camera history, task instruction, available robot state, proposed/recent executed actions, and timestamps; privileged simulator object poses and task-success predicates remain evaluation-only information. Changes to the VLA's instruction are deferred to v2 by scope choice, alongside automatic harness modification, so v1 can isolate execution corrections and outcome-linked memory.
